Install on macOS

Three steps, about a minute.

  1. Download and open the .dmg

    Drag Kube Desk to Applications.

  2. Open it the first time

    Releases aren’t notarized yet, so macOS asks before opening them. In Applications, right-click Kube Desk and choose Open, then Open again. Or remove the quarantine flag from Terminal:

    Terminal
    $ xattr -dr com.apple.quarantine "/Applications/Kube Desk.app"
  3. Your clusters are already there

    Kube Desk reads every context in ~/.kube/config and $KUBECONFIG. Add more with the + at the bottom of the cluster rail: pick a file, paste a kubeconfig, or enter a server and a token.

Using GKE, EKS or AKS? Their credential plugins (gke-gcloud-auth-plugin, aws, kubelogin) work even when Kube Desk is opened from Finder, because it loads your login shell’s PATH.

Install on Linux

Install it for yourself in ~/.local, without root. It adds Kube Desk to your applications menu and keeps it up to date:

Terminal
$ curl -fsSL https://pub-e3b2030c705649ef87d35925ea3331eb.r2.dev/install.sh | sh

Or install the Debian package, for x64 or arm64, which brings what it needs:

Terminal
$ sudo apt install ./Kube-Desk-latest-linux-amd64.deb

Kube Desk needs GTK 3 and WebKitGTK 4.1: libwebkit2gtk-4.1-0 on Debian and Ubuntu, webkit2gtk4.1 on Fedora, webkit2gtk-4.1 on Arch. The assistant keeps its API key in the Secret Service (GNOME Keyring, KWallet, KeePassXC).

Install on Windows

  1. Download and run the installer

    Kube Desk Setup installs Kube Desk for you and adds it to the Start menu.

  2. Let SmartScreen run it

    The installer isn’t signed yet, so Windows may warn the first time. Choose More info, then Run anyway.

Kube Desk uses WebView2, which comes with Windows 10 and 11, and keeps the assistant’s API key in the Credential Manager.

Updates

Kube Desk checks for updates once a day, and you can check any time from Kube Desk → Check for Updates… or ⌘K. Updates show what’s new before you install them.

  • Signed. Every release is signed with Ed25519, and the app checks the signature before installing.
  • Small. Usually only the changes are downloaded: going from 0.6 to 0.7 is 7 MB.

Set up the assistant

The assistant, ⌘J, is Claude through your own cloud account. Pick one; you only need one of them.

  1. Make Claude available to you

    Microsoft Foundry: deploy a Claude model in the Foundry portal, such as claude-opus-5-5. Its Details tab has the Target URI and the key.

    Google Vertex AI: enable the Claude model in Model Garden, then sign in once in a terminal:

    Terminal
    $ gcloud auth application-default login
  2. Tell Kube Desk where it is

    Open Assistant settings from ⌘K. For Foundry, enter the resource name or the Target URI, the key and the deployment name; the key goes to the system’s credential store (the keychain on macOS). For Vertex AI, enter the project and the region (global by default). Save and test checks the connection.

  3. Ask

    Press ⌘J and ask, for example, “Which pods are failing in this cluster, and why?” Changes it proposes wait for your approval. Past chats are under the clock in its header.

Connect an AI agent

Kube Desk is an MCP server for Claude Code, Cursor, Codex, Claude Desktop and other MCP clients. It is off until you turn it on.

  1. Turn on the server

    Open AI agents, from the robot in the title bar or from ⌘K.

  2. Choose what agents may do, per cluster

    Off, Read or Propose changes. Every cluster starts at Off. Proposed changes wait for your approval in Kube Desk, with a diff and what they affect.

  3. Add it to your client

    Kube Desk shows the command for each client, with your token filled in. For Claude Code:

    Terminal
    $ claude mcp add --transport http kubedesk http://127.0.0.1:47428/mcp \
    --header "Authorization: Bearer <token from Kube Desk>"

    Clients that start servers as processes (Cursor, Claude Desktop, Codex) run Kube Desk’s bridge instead. It opens Kube Desk if it isn’t running:

    MCP server command
    "/Applications/Kube Desk.app/Contents/MacOS/Kube Desk" mcp --config <path shown in the app>

Then ask, for example, “Why is checkout failing in production-eu?”

Build from source

For Intel Macs, other systems, or to change it. The code is cross-platform: MyGo uses WebKitGTK on Linux and WebView2 on Windows. You need Go 1.27 or later and Bun; no C toolchain.

Terminal
$ git clone https://github.com/ftech-vn/kubedesk.git
$ cd kubedesk
$ bun install
$ bun run build      # build/darwin-arm64/Kube Desk.app and a .dmg

Build for other platforms, or a universal Mac app:

Terminal
$ bun run build -- -platform darwin/universal,linux/amd64,windows/amd64

Notarized macOS builds and a signed Windows installer are on the roadmap.

Requirements

macOS
macOS 12 Monterey or later, Apple silicon. Intel: build from source
Linux
x64 or arm64, with GTK 3 and WebKitGTK 4.1
Windows
Windows 10 or 11, x64, with WebView2
Clusters
Any Kubernetes API server your kubeconfig reaches
Metrics (optional)
metrics-server, for CPU and memory
Helm (optional)
The helm command, to roll releases back. Reading them needs nothing
Assistant (optional)
Claude in Microsoft Foundry or Google Vertex AI
Network
Your API servers, the update server, and the assistant’s cloud if you use it. No telemetry
Disk
About 70 MB
