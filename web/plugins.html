Install a plugin

Install in Kube Desk opens Kube Desk 0.8 or later, which shows the plugin and asks before it installs it. Or, in Kube Desk, press ⌘K, choose Plugins…, then Find plugins. Kube Desk checks that the registry signed the plugin's archive, and keeps the plugins you install up to date from Updates.

A plugin runs inside Kube Desk with the app's access, so install those you trust. The changes it asks for go through Kube Desk's diff and confirmation, and read-only clusters refuse them.

Publish yours

  1. Write it

    A plugin is a React bundle and a package.json. Start from the template with scripts/new-plugin.sh, and load its folder in Kube Desk while you write it: the plugin guide has the API and two examples.

  2. Describe it

    Give it a README.md, an icon.png (256 px, square) as kubedesk.icon, a few kubedesk.features, and the Kube Desk versions it works with in engines.kubedesk.

  3. Send it

    Open an issue with a link to its source. Once it is reviewed, it is published here and in Kube Desk, signed by the registry.
